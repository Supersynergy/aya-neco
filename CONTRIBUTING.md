# Contributing

AYA-NECO is a prototype for research and public-goods exploration.

## Start

```bash
just setup
just check
just dev
```

## Contribution Rules

- Keep demo units clearly labeled.
- Do not add real-money, token-sale, custody, redemption, or return language.
- Add tests for domain-rule changes.
- Keep UI effects tied to state, proof, trust, focus, or completion.
- Document integration changes in `docs/`.

## Good First Issues

- Add another demo contribution type.
- Add a new receipt example.
- Add an IOTA testnet proof adapter.
- Wrap the ONCE/WODA manifest into a runtime command.
- Add a verifier for external MRV signatures.
