# AYA-NECO v0.2.0

Backend architecture release.

## What Changed

- Added a real Bun HTTP API in `apps/api`.
- Added SQLite persistence for identity and ledger events.
- Extracted shared rules into `packages/domain`.
- Wired the React UI to the backend instead of in-memory mock state.
- Added WODA-envelope export from backend receipts.
- Added an IOTA proof-preparation demo event.
- Added backend/API tests that prove persistence through HTTP.

## Why It Matters

The UI is no longer the source of truth. A contribution now goes through:

```text
React UI -> Bun API -> shared domain rules -> SQLite ledger -> receipt/envelope
```
