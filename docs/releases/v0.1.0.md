# AYA-NECO v0.1.0

First public proof-lab release.

## What You Can Do

- Run the local React app.
- Accept a common-good contribution.
- Create a Planedo-style impact proof.
- Apply Gradido-style monthly transience.
- Inspect hash-chain ledger events.
- Export a JSON receipt.
- Generate ONCE/WODA object envelopes from receipts.

## Why It Matters

This release proves the smallest useful loop:

```text
identity -> contribution -> rule -> ledger event -> receipt -> adapter boundary
```

It deliberately avoids real-money, custody, token-sale, eIDAS, and official partner claims.
