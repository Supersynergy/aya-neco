# Security

AYA-NECO is a local-first research prototype.

## Supported Scope

Security reports should focus on:

- dependency vulnerabilities;
- malicious receipt parsing;
- misleading demo/production boundaries;
- unsafe future adapter assumptions;
- accidental secret leakage.

## Out Of Scope

- financial custody risk, because the app does not custody assets;
- token economics, because the app does not issue production tokens;
- eIDAS/KYC compliance, because the app does not claim certification.

## Reporting

Open a private report or contact the maintainer before publishing exploit details.
